# Генератор шпаргалок

Веб-приложение для генерации коротких учебных шпаргалок через Gemini.

## Что умеет

- По названию темы: например, «Векторы».
- По полному тексту параграфа.
- Выбор школьного предмета.
- Несколько карточек на одну тему.
- Структурированный JSON-ответ от Gemini.
- API-ключ хранится только на сервере в переменной окружения.

## Запуск локально

1. Установи Node.js.
2. Выполни:

```bash
npm install
```

3. Скопируй `.env.example` в `.env`.
4. В `.env` укажи настоящий ключ:

```text
GEMINI_API_KEY=твой_ключ
```

5. Запусти:

```bash
npx vercel dev
```

Открой адрес, который покажет Vercel.

## GitHub

Не добавляй `.env` в репозиторий. `.gitignore` уже настроен.

## Vercel

После подключения репозитория добавь в Project Settings → Environment Variables:

- `GEMINI_API_KEY` — твой Gemini API key
- `GEMINI_MODEL` — по желанию; по умолчанию `gemini-3.8-flash`

После этого сделай redeploy.

Важно: не вставляй Gemini API key в `index.html`, браузерный JavaScript или публичный репозиторий.


## Новые функции

- История всех сгенерированных наборов хранится в браузере.
- Поиск по истории.
- Удаление отдельных карточек или всей истории.
- Кнопка копирования текста карточки.
- Экспорт истории в PDF через печать браузера (корректно поддерживает русский текст).
- Переключатель «Кратко / Подробно» при генерации.
